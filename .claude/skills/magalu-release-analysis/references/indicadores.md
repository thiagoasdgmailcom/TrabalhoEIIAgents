# Indicadores — Conjunto Inicial

Este é um ponto de partida, não uma lista fechada. Releases variam de trimestre a trimestre; se um indicador relevante aparecer fora desta lista, registre-o (com evidência) e sinalize como pendência para ampliar este conjunto no futuro, em vez de ignorá-lo.

Para cada indicador, ao extrair, registre também: segmento (consolidado / lojas físicas / e-commerce / marketplace / 1P / 3P — quando aplicável), tipo de período (trimestre isolado / acumulado / anual) e se é ajustado ou reportado.
